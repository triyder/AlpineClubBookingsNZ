- **Email bodies can now be formatted — bold, headings and bullet lists
  (fork #38).** The Admin → Email Messages body editor gains a small
  formatting toolbar: `**bold**`, `*italic*`, `# heading` and `- ` bullet
  lines render styled in the club's email theme, and Preview shows exactly
  what a member will receive. Everything else stays plain text — typing HTML
  still shows the angle brackets literally, so nothing an admin pastes can
  become markup. Formatting only applies to bodies saved from now on: wording
  saved before this release keeps rendering exactly as it always has (a
  literal asterisk in an old body is not reinterpreted) until an admin
  re-saves it from the editor.
