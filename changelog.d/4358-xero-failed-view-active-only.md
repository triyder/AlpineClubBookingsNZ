- **The Xero Operations Failed view now shows only the failures that still need
  attention (#4220).** Choosing Failed under Status also picks "Active only"
  under Failure, so rows that a later run repaired or replaced, or that an officer
  marked resolved in Xero, no longer sit beside the one that really needs you. A line
  above the list says how many are hidden, and "Show them" brings them back;
