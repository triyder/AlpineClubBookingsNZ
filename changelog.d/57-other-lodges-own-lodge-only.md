- **The Other lodges list is now read-only except for your own lodge, which the central server names (#52).** On **Admin → Lodges → Other lodges** the Add, Edit and Delete buttons are gone for other clubs' lodges. A lodge can only change its own entry, through an **Edit my Lodge** button that opens the popup; the lodge name stays fixed. Which lodge is yours is decided on the central server (mapped to your site's API key) and sent back on every download, so it needs the connected central server on API version 2.0. Until a download has told this site which lodge is its own, the list is read-only and says so.

  Other clubs' booking-officer phone numbers are no longer shown on this screen, and this site no longer keeps one for a lodge it does not own. A number stored by an earlier download is cleared on that lodge's next download; copies already in database backups and older audit entries remain. The nightly upload sends only your own lodge, so a stale local edit to another club's lodge is never sent. Disconnecting the central server, changing its address or replacing the API key makes the site forget which lodge is its own until the next download. The operator guides (`docs/guides/lodges.md`, `docs/guides/integrations.md`) say the same.
