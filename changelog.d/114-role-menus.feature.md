- **One admin menu per role (#108).** The admin sidebar's switcher now offers **Admin**, **Bookings**, **Membership**, **Content**, **Finance** and **Treasurer** menus, one for each role a person holds, chosen from that role's permission areas so club-made roles follow the same rule. A Full Admin sees **Admin** only, plus any other role they hold; people without an admin-wide role no longer get a **Full admin** button. **Treasurer** is the **Finance** menu plus Subscriptions, Integrations and the refund and unpaid-stay queues. The sidebar no longer repeats the Member Dashboard and Admin Dashboard links from the top bar. **Who's at the lodge** has left the top bar for everyone and is now a button under **Open Kiosk** on the dashboard's Lodge Kiosk card, and an account whose User Type is Admin no longer sees **My Bookings** in the top bar. The menus are display only — page access is unchanged.
